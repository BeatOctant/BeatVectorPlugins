# octantvector-clap

OctantVector のビュー `clap_htsat_unfused`、`vocal_clap_htsat_unfused`、`clap_concepts`（LAION CLAP、HTS-AT unfused）。使い方は [OctantVectorPlugins の README](../README.md) にあります。

- このパッケージのコード: MIT（LICENSE）
- モデル [laion/clap-htsat-unfused](https://huggingface.co/laion/clap-htsat-unfused)（revision `8fa0f1c6d0433df6e97c127f64b2a1d6c0dcda8a`）: Apache-2.0。モデルのファイルはこのパッケージに含まれず、`octantharvest models` が `models_dir` に置きます。
